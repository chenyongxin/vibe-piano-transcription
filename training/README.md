# 训练报告（training reports）

这里按时间记录**每次大跑**（超过 1 小时，或包含多组实验的队列）的完整事实，
和 `experiments/registry/` 的机器可读 JSON 互补：

- `experiments/registry/`：给程序/表格用的实验条目（配置、指标、检查点哈希）；
- `training/`：给人读的报告（当时怎么想的、跑了多久、结果说明了什么、下一步猜什么）。

## 什么时候写一份

满足任一条件就写：

1. 单次训练超过 1 小时；
2. 一次跑多组对照实验（例如通宵队列）；
3. 改动了训练配方（标签口径、损失、模型结构、数据增强）。

## 每份报告必须包含

| 部分 | 内容 |
|---|---|
| 基本信息 | 日期与起止时间、目的、硬件、数据版本、启动命令 |
| 配置 | 步数、batch、学习率、标签口径、保存策略 |
| 结果 | 验证集指标 + 开发集/留出集评测（onset 与 note 两套口径） |
| 观察与分析 | 哪些符合预期、哪些异常、可能原因 |
| 下一步猜想 | 可验证的假设 + 实验设计（不要写成空泛的"继续调参"） |
| 相关链接 | 实验登记 JSON、文档章节、日志与检查点路径 |

## 文件命名

```text
training/YYYY-MM-DD_<主题简写>.md
```

例如：

- [`2026-11-05_m3_full_71k.md`](2026-11-05_m3_full_71k.md)：M3 全量 20 轮训练；
- [`2026-11-06_m3_5_nightly.md`](2026-11-06_m3_5_nightly.md)：M3.5 首轮四组对照实验。

新报告从 [`TEMPLATE.md`](TEMPLATE.md) 复制结构。
