# App changelog

当前版本：**0.2.5**。本文只记录 Web app 的版本变化；模型训练实验见
`../training/`。

## 0.2.5 — 2026-11-15

### 优化

- 首屏/队列不再展示总容量数字，只说明单首不超过 500 MB；
- 转录中的曲目增加进度条，直接显示当前阶段百分比；
- 下载文件名改为 `<上传名>_score.pdf` / `<上传名>_score.musicxml` / `<上传名>_score.mid`，避免多首曲目互相覆盖。

### 时值修复

- offset 结束时间搜索窗口从「起点后 160 帧」缩短为「起点后 20 帧」，并把阈值提高到 0.7；
- 旧窗口会把后面的释放峰误配给当前音，holdout note F1 从 0.4046 提升到 0.4533，难段落聚合 note F1 从 0.212 提升到 0.293；
- 完整 test split 验证进行中。

## 0.2.4 — 2026-11-15

### 修复

- 播放时手动滚动谱面不再被自动跟随立即拉回；用户滚动后暂停自动跟随，
  翻页/回到当前/点击小节/重新播放时恢复。
- 前端静态资源查询参数更新到 `v=0.2.4`。

### 已知问题

- 极快速段落的音画对齐仍可能差几十毫秒，原因见 `10_limitations.md`。

## 0.2.3 — 2026-11-15

### 新增

- 后台多曲目完成提示：用户正在看谱/播放时，只显示非阻塞 toast，不切页、不暂停；
- 上传限制提升为最多 5 首、单首 ≤ 500 MB；
- `score.mid` 导出校验失败时回退到原始事件 MIDI，长曲目不再整体失败。

### 优化

- 播放进度、当前小节高亮改用原始音频时间轴；
- 翻页自动回页首，播放中的当前小节自动滚入视口；
- timing 采样从 0.10 s 提高到 0.04 s，并加入每个音符起点；
- 服务端对 HTML/静态资源返回 `no-store`，避免浏览器缓存旧脚本。

## 0.2.2 — 2026-11-14

### 修复

- 点击谱面音符或小节可以跳转到对应播放位置；
- 不再只按点击的 Y 坐标投影，增加 `idTimes` / `measureTimes` 索引和 2D 最近小节兜底。

## 0.2.1 — 2026-11-14

### 修复

- 前端 `app.js` 被浏览器缓存导致上传限制文案不更新；
- 给静态资源加版本查询参数，服务端增加 `no-store` 缓存头。

## 0.2.0 — 2026-11-14

### 新增 / 优化

- app 默认模型切换为 `hybrid_reg2`，推理链路改为
  分类解码 + `onset_reg` 亚帧起点修正；
- 标题从内部代号改为「钢琴转录」，重做首页、卡片、按钮、页脚、favicon；
- 任务结果增加 `model` 字段，明确实际使用的模型路径；
- CPU / GPU Dockerfile、compose profile、GitHub Actions 构建流程；
- 中英文 README 与 INSTALL 文档。

## 0.1.0 — 2026-11-04

### 初始版本

- FastAPI + 单页前端：上传音频、后台转录、谱面分页查看、MusicXML/PDF/MIDI 下载；
- 后续加入多曲目队列、单页左右翻页、播放跟随和谱面高亮。

## 已知问题总览

| 问题 | 状态 / 说明 |
|---|---|
| 快速音型、琶音、短倚音、三连音 | 受 32 ms 帧率、onset 峰间距和记谱量化限制；见 `10_limitations.md` |
| 音画仍有少量不同步 | 回放是原始事件时间轴，谱面是量化时间轴，映射存在近似；见 `10_limitations.md` |
| 长曲目第 20 页以后不显示 | 渲染页数有意限制为 20，音频仍完整 |
| `score.mid` 与谱面可能有时间差 | 谱面 MIDI 来自 verovio；导出异常时会回退到原始事件 MIDI |
| Docker 镜像未在本机完整构建验证 | 需要能访问对应 registry；GitHub Actions 需在仓库中实际运行 |
| 模型权重不进入 git | 需要 Release 附件、挂载或 `PIANO2_CKPT` |

## 版本规则

- `0.x.0`：模型/产品行为变化；
- `0.x.y`：UI、交互、部署和 bug 修复；
- 每个版本应同步更新 README、INSTALL 或对应 docs 中的行为说明。
