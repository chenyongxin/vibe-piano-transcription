# M0.5 步骤 2：状态机参数搜索（结论：参数不是杠杆，结构才是）

日期：2026-11-01
代码：`m0/decode_v2.py`、`m0/m05_step2.py`、`m0/m05_step2b.py`
产物：`outputs/M0/m05/step2_grid.csv`、`step2_decoder_comparison.csv`

---

## 1. 实验设置

- 调参集：Haydn（稀疏）、Mozart（中等）；holdout：Beethoven（密集），只评一次。
- 网格 108 组：onset_threshold（0.4/0.6/0.7）× min_note_frames（2/3/6）× release_frames（3/5/10）× min_reattack_gap（0.08/0.15）× merge_gap（0.05/0.20）；谐波抑制固定关闭。
- 主指标：onset-only F1；硬约束：precision ≥ 0.85。

## 2. 网格搜索结果

| 指标 | Haydn | Mozart | 均值 | Beethoven（holdout） |
|---|---|---|---|---|
| 最优 F1 | 0.774 | 0.806 | **0.790** | 0.628 |
| 对应 precision | 0.965 | 0.978 | 0.972 | 0.901 |

最优配置：onset_threshold 0.70、min_note_frames 2、release_frames 3、min_reattack_gap 0.08、merge_gap 0.05。

验收：未通过（目标 0.855 / 0.854 / 0.717；实际 0.774 / 0.806 / 0.628）。
但 precision 全部 ≥ 0.85——**精确率并没有像预期那样掉下去**。

## 3. 消融：参数几乎都不起作用

| 改动 | Haydn F1 | Mozart F1 | 结论 |
|---|---|---|---|
| 最优配置 | 0.772 | 0.807 | — |
| min_note_frames 2→1 | 0.796 | 0.828 | 小幅提升 |
| release_frames 3→1 | 0.789 | 0.841 | 小幅提升 |
| merge_gap 0.05→0 | 0.772 | 0.807 | 无变化 |
| min_reattack_gap 0.08→0 | 0.772 | 0.807 | 无变化 |
| peak_distance 5→1 | 0.772 | 0.808 | 无变化 |
| prominence 0.005→0.06 | 完全相同 | 完全相同 | 无影响 |
| 全部放开 | 0.818 | 0.867 | 仍低于天花板 |

两个发现：

1. **多个参数互相遮蔽**：`peak_distance=5` 已经限制同键峰距（160 ms），所以 `min_reattack_gap` 改成多少都没用；`merge_gap` 也够小，不起作用。
2. **即使全部放开，状态机也只能到 0.818/0.867**，而纯峰值天花板是 0.950/0.949。差的这 0.1 来自状态机的**结构**，不是参数：它把「起点」和「音尾」耦合在一起，音尾判定（frame 迟滞）反过来会删掉真实的起点。

## 4. 解码器重设计：峰值定起点、frame 定终点

把两件事解耦：

- 起点：onset 峰值（和纯峰值检测完全一样）；
- 终点：从起点往后，frame 概率连续低于阈值若干帧就算结束；
- 去掉重击间隔、最短音值、同音合并这些门限。

三种解码器对照（onset-only F1 / precision）：

| 曲目 | A 原管线 | B 最优状态机 | C 峰值+frame |
|---|---|---|---|
| Haydn | 0.196 / 0.946 | 0.774 / 0.965 | **0.950 / 0.934** |
| Mozart | 0.220 / 0.972 | 0.806 / 0.978 | **0.949 / 0.947** |
| Beethoven | 0.166 / 0.916 | 0.628 / 0.901 | **0.797 / 0.775** |

新解码 C 的 F1 与纯峰值天花板完全一致，验收里的 F1 三项全部通过；**唯一没过的是密集曲目的 precision（0.775 < 0.85）**。

结论：参数搜索的方向是错的，结构门限才是召回杀手；把结构换掉之后，召回问题一步解决，代价是密集曲目的假阳性变多——这正好是步骤 3（条件式谐波抑制）要解决的问题。

## 7. 下一步（步骤 3）

目标改为：**把密集曲目的 precision 从 0.775 拉回 ≥0.85，同时保持 F1 ≥ 0.79**。
手段：条件式谐波抑制（逐帧、局部、取最强衰减、需要 frame 不支持的证据）。
另外记谱层要加一条：谱面总时长用音频兜底（步骤 1 发现的 -18.8% 问题）。
