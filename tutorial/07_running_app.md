## 计划中的使用方式（Docker + 浏览器）

```text
① 对方电脑装好 Docker（Windows/macOS/Linux 均可）
② 导入镜像：docker load -i piano2-app.tar
③ 启动：docker run --gpus all -p 8000:8000 piano2-app
④ 浏览器打开 http://localhost:8000
⑤ 拖入一段钢琴录音 → 等几秒到几十秒 → 看谱、下载 MusicXML/MIDI/PDF、播放
```
