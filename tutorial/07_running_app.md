# 07 运行浏览器应用

> 状态：**M4.2 可用**（本机运行）：多曲目队列、单曲/多曲、单页翻页、真实钢琴回放。
> Docker 镜像分发完成后，本文会补上「接收方」的完整傻瓜步骤；当前内容适用于开发者/本机试用。

## 摘要

本文是浏览器应用的使用与运行说明：如何在本机启动后端、上传音频、看谱与回放、下载文件，以及常见问题怎么排查。读者不需要了解前端或 FastAPI；照着步骤就能把应用跑起来。

## 前置条件

| 项目 | 要求 |
|---|---|
| Python 环境 | 已安装本项目依赖（`pip install -e .`）；开发用的是 `piano` 容器 |
| 模型权重 | `models/best.pt`（约 135 MB）；没有的话用 `PIANO2_CKPT=/path/to/best.pt` 指定 |
| 真实钢琴音色（可选） | `fluidsynth` + `FluidR3_GM.sf2`；没有时自动回退到简易合成器 |
| 浏览器 | Edge / Chrome / Firefox 任意现代浏览器 |
| 显卡 | 可选；有 NVIDIA GPU 更快，没有 GPU 走 CPU（5 分钟音频约 9 秒） |

## 使用步骤

1. **打开页面**：浏览器访问 `http://127.0.0.1:8000`，右上角会显示推理设备；
2. **选文件**：把音频拖进虚线框，或点「选择文件」；可以一次选多首（最多 10 首、总大小 ≤ 100 MB）；
3. **确认列表**：选择后**不会自动转录**，而是进入「曲目列表」；可以「删除」、继续「添加」，确认后点「开始转录」；
4. **等待**：逐首串行转录，每首显示自己的状态和阶段；
5. **看结果**：
   - 只有 1 首：完成后直接进入谱面；
   - 多首：显示曲目列表，点「打开乐谱」进入；
   - 谱面一次显示一页，用「上一页 / 下一页」或键盘 ←、→ 翻页；
   - 播放时当前页自动跟随，当前小节淡黄色块 + 当前音符红色高亮；
   - 播放中翻到别的页，会出现「回到当前」；点它回到播放页并恢复跟随；暂停时该按钮不显示；
   - 页面内部可以纵向滚动，但**不会自动滚动**；
   - 播放器可试听（有 FluidSynth 时为真实钢琴音色），用播放器自带进度条拖动；
   - 三个下载按钮：MusicXML / PDF / MIDI；
6. **追加曲目**：转录完成后仍可「继续添加」；「开始转录」只处理新加的待转录曲目，已完成的不会重跑。

## 输出文件说明

| 文件 | 用途 |
|---|---|
| `score.musicxml` | 乐谱源文件，可用 MuseScore 打开编辑 |
| `score.pdf` | 直接打印/查看 |
| `score.mid` | 标准 MIDI，可导入 DAW 换更好的钢琴音色 |
| `preview.wav` | 网页内回放音频；有 FluidSynth 时是真实钢琴音色，否则是简易合成器 |
| `page_*.svg` / `page_*.png` | 分页矢量谱 / 图片谱 |

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面显示「后端未连接」 | 服务器没启动或端口不对，检查 `uvicorn` 是否在跑 |
| 右上角显示「⚠ 模型缺失」 | `models/best.pt` 不存在，用 `PIANO2_CKPT` 指定权重 |
| 端口 8000 被占用 | 换端口：`--port 8001`，浏览器相应改地址 |
| 上传后失败「不支持的格式」 | 只接受 wav / mp3 / m4a / flac / ogg / aac / webm |
| 选完文件没有自动转录 | 这是 M4.2 的正常流程：先进入曲目列表，点「开始转录」才会上传并转录 |
| 曲目列表无法添加 | 最多 10 首、总大小不超过 100 MB；删掉一些再试 |
| 只能看到一页 | 多页曲目用「上一页 / 下一页」或键盘 ←、→ 翻页；只有 1 页时控件隐藏 |
| 播放回放不像钢琴 | 服务器缺少 FluidSynth 或 SoundFont，正在用简易合成器回退；装好后重启服务即可 |
| 谱面时值不准 | 已知问题（M3.5 修复中）；onset 已较准，节奏细节还有误差 |
| 音频很长 | 建议 ≤ 5 分钟；更长音频会变慢并占更多内存 |

## Docker 版（M4.2 计划）

```text
接收方：docker load -i piano2-app.tar
        docker run --gpus all -p 8000:8000 piano2-app
        浏览器打开 http://localhost:8000
```

注意：macOS 上 Docker 无法使用 Apple GPU，会走 CPU；Windows 需要 WSL2 + NVIDIA 驱动。

## 小结

三步就能用：

```bash
# ① 安装依赖（首次）
pip install -e .

# ② 启动后端（在仓库根目录）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# ③ 浏览器打开
# http://127.0.0.1:8000
```

然后把一段钢琴录音拖进页面，选完确认列表，点「开始转录」；等几秒到几十秒，就能看谱、下载、回放。
